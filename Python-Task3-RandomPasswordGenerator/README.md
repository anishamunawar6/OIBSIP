# Random Password Generator

## Description
Random Password Generator is a Python GUI application developed using Tkinter. It generates secure and customizable passwords based on user-selected options.

## Features
- Generate secure random passwords
- Password length validation (minimum 8 characters)
- Select Uppercase, Lowercase, Numbers and Symbols
- Password Strength Indicator (Weak, Medium, Strong)
- Copy password to clipboard
- Exclude ambiguous characters (0, O, l, 1)
- Last 5 generated passwords history

## Technologies Used
- Python
- Tkinter
- secrets
- string
- random
- pyperclip

## How to Run
1. Open the project in VS Code.
2. Install pyperclip:
   ```
   pip install pyperclip
   ```
3. Run:
   ```
   python password_generator.py
   ```
